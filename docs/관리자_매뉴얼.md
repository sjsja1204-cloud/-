# 담아가넷 관리자 매뉴얼

이 문서는 개발자 없이 홈페이지를 직접 운영하기 위한 안내서입니다.
모든 작업은 **관리자 계정으로 로그인한 뒤** 화면 위쪽 메뉴에서 합니다.

- 로그인 주소: `https://(홈페이지 주소)/login`
- 휴대폰에서도 됩니다. 메뉴가 길면 옆으로 밀어서 찾으세요.

## 먼저 알아 두기: 바로 반영되는 것과 '사이트에 반영하기'가 필요한 것

| 메뉴 | 반영 방식 |
|---|---|
| **요금표**, **메인 화면** | 고쳐도 바로 바뀌지 않습니다. **임시저장 → 미리보기 → 사이트에 반영하기** 순서로 누르세요. 잘못되면 **이전 버전**으로 되돌릴 수 있습니다. |
| **팝업**, **사이트 설정**, **게시판 관리**, **직원 관리** | **저장**을 누르는 즉시 반영됩니다. |

요금표·메인 화면 위쪽에는 지금 상태가 색깔로 표시됩니다.

- 🟩 **사이트에 반영된 내용과 같아요**: 고객이 보는 화면과 같습니다.
- 🟨 **저장하지 않은 변경이 있어요**: 고친 내용이 아직 어디에도 저장되지 않았습니다. 이 상태로 창을 닫으면 사라집니다.
- 🟦 **임시저장됨 · 아직 사이트에 반영 안 됨**: 저장은 됐지만 고객에게는 아직 이전 내용이 보입니다.

`[스크린샷: 요금표 화면 위쪽 상태 표시와 버튼들]`

## 1. 요금 바꾸기

1. 위쪽 메뉴에서 **요금표**를 누릅니다.
2. 왼쪽 **통신사** 목록에서 바꿀 통신사(예: KT)를 누릅니다.
3. **요금표** 탭의 표에서 바꿀 칸을 누르고 숫자만 입력합니다.
   - 콤마(,)는 자동으로 붙습니다. 글자는 입력되지 않습니다.
   - 빨간 칸은 비어 있다는 뜻입니다. 빈칸이 있으면 사이트에 반영할 수 없습니다.
4. 위쪽 **임시저장**을 누릅니다.
5. **미리보기**를 누르면 새 창에 실제 홈페이지 모양이 뜹니다.
   - 맨 위에 파란색 "미리보기 화면" 띠가 보이면 정상입니다.
   - 이 화면은 관리자에게만 보입니다.
6. 확인이 끝나면 다시 관리자 화면으로 와서 **사이트에 반영하기**를 누르고, 확인 창에서 **확인**을 누릅니다.
7. "사이트에 반영했습니다" 메시지가 나오면 끝입니다. 고객 화면에 바로 보입니다.

`[스크린샷: 요금표 편집 화면]`

> **사이트에 반영하기 버튼이 눌리지 않을 때**: 빨간 안내 상자의 **보기 ▼**를 누르면 고쳐야 할 곳이 나옵니다. 예: "KT › 요금표 — '1G' × '에센스' 요금 칸이 비어 있습니다."

**표 아래 안내 문구**: 요금표 밑 상자에 한 줄에 하나씩 쓰면, 홈페이지 표 아래에 `※ 문구`로 나옵니다.

## 2. 통신사·상품 추가하기

### 통신사 추가
1. **요금표** → 왼쪽 목록 아래 **+ 통신사 추가**를 누릅니다.
2. **기본 정보** 탭이 열립니다.
   - **통신사 이름**, **대표 색상**, **한 줄 소개**를 입력합니다.
   - **주소용 영문 이름**: 홈페이지 주소에 쓰입니다. 예: `kt` → `/internet/kt`. 영어 소문자·숫자·`-`만 쓸 수 있습니다.
   - **상담 폼에서 미리 선택할 통신사**: 이 통신사 페이지의 상담 폼에서 미리 체크될 값입니다.
3. 새 통신사는 처음에 **숨김** 상태입니다. 요금을 다 채운 뒤 **홈페이지에 보이기**를 체크하세요.
4. **요금표** 탭에서 상품과 요금을 입력합니다 (아래 참고).
5. **임시저장 → 미리보기 → 사이트에 반영하기**를 누릅니다.

### 인터넷 상품(행)·TV 상품(열) 추가
- 표 아래 **+ 인터넷 상품(행)**: 새 줄이 생깁니다.
- 표 오른쪽 **+ TV 상품(열)**: 새 칸이 생깁니다.
- 새로 생긴 칸은 빨간색(빈칸)입니다. 이름과 요금을 모두 채워야 반영할 수 있습니다.
- 이름 아래 작은 버튼으로 정리합니다. **▲▼ / ◀▶**는 순서 바꾸기, **✕**는 삭제입니다.

### 순서 바꾸기·숨기기·삭제
- 왼쪽 통신사 목록의 **▲▼**로 메뉴와 요금 비교에 나오는 순서를 바꿉니다.
- **숨기기**: **기본 정보** 탭에서 **홈페이지에 보이기** 체크를 끄면, 내용은 남겨 둔 채 홈페이지에서만 빠집니다.
- **삭제**: **✕**를 누르면 확인 창이 뜹니다. 지워도 **이전 버전**에서 되돌릴 수 있습니다.

`[스크린샷: 통신사 추가 후 기본 정보 탭]`

## 3. 결합할인표 고치기

1. **요금표** → 통신사 선택 → **결합할인표** 탭을 누릅니다.
2. 고칠 표의 제목줄을 누르면 펼쳐집니다.
3. 할 수 있는 일:
   - **표 제목·설명** 수정
   - **열 이름** 수정, **+ 열**로 열 추가 (◀▶ 순서, ✕ 삭제)
   - 칸 내용 수정: 보이는 그대로 입력합니다. 예: `5,500원`, `-`, `최대 3회선`
   - **+ 줄 추가**, 줄 오른쪽 **▲▼✕**
   - **표 아래 안내 문구**: 한 줄에 하나씩
4. **혜택 박스** (예: "TV 2대 이상 가입 시 추가 혜택")
   - **표 위에 보이는 혜택 박스** / **표 아래에 보이는 혜택 박스** 중 원하는 곳에서 **+ 혜택 박스**를 누릅니다.
   - 박스 종류:
     - **이름 + 값 목록**: 예) 베이직 / 7,370원
     - **글머리 목록**: 한 줄에 하나씩
   - **박스 아래 메모**: 선택입니다. 예) "월 사용료 (셋탑박스 별도)"
   - **표 위로 옮기기 / 표 아래로 옮기기**로 위치를 바꿉니다.
5. 표를 새로 만들려면 맨 아래 **+ 결합할인표 추가**를 누릅니다.
   - 결합할인표가 하나도 없는 통신사는 홈페이지 '결합할인' 메뉴에 나오지 않습니다.
6. **임시저장 → 미리보기 → 사이트에 반영하기**를 누릅니다.

`[스크린샷: 결합할인표 편집 화면]`

## 4. 이벤트 팝업 올리기·내리기

팝업은 **저장하는 즉시** 홈페이지에 반영됩니다.

### 새 팝업 올리기
1. 위쪽 메뉴 **팝업** → **+ 새 팝업**을 누릅니다.
2. **이미지 올리기**를 누르고 파일을 고릅니다.
   - jpg·png·webp만, 2MB 이하만 올릴 수 있습니다.
   - 크기는 자동으로 줄여서 저장됩니다.
3. **누르면 이동할 곳**을 정합니다.
   - `#apply`: 같은 화면의 상담 신청 폼으로 이동
   - `/event`: 홈페이지 안 다른 메뉴
   - `https://…`: 다른 사이트 (새 창)
4. **시작일·종료일**을 정합니다.
   - 비우면 바로 시작하고, 끝나는 날이 없습니다.
   - 종료일 다음 날부터는 자동으로 안 뜹니다.
5. **켜기**를 체크한 채로 **저장**을 누릅니다.

이미지가 없으면 **제목·내용·버튼 문구**를 넣어 글자로 된 팝업을 만들 수 있습니다.

### 내리기
- 목록에서 **켜짐** 체크를 끄면 바로 안 뜹니다. 휴대폰에서도 됩니다.
- **삭제**는 되돌릴 수 없습니다. 잠시 내리는 것이라면 끄기를 쓰세요.

### 여러 개 띄우기
- 켜져 있는 팝업이 여러 개면 목록 순서대로 겹쳐서 뜹니다. 순서는 **▲▼**로 바꿉니다.
- 고객은 팝업마다 "오늘 하루 보지 않기"를 누를 수 있습니다.

`[스크린샷: 팝업 목록과 켜기/끄기]`

## 5. 메인 문구 바꾸기

1. 위쪽 메뉴 **메인 화면**을 누릅니다.
2. **맨 위 배너** 탭: 첫 화면의 큰 배너입니다. 여러 개면 5초마다 넘어갑니다 (최대 5개).
   - **작은 제목**: 제목 위 주황 꼬리표
   - **큰 제목**: 줄을 바꾸면 홈페이지에서도 줄이 바뀝니다
   - **부제목**, **버튼 문구**, **버튼 누르면 이동할 곳**
   - **색상**: 주황 / 남색 / 민트
   - **배경 이미지**: 선택입니다. 오른쪽에 깔리고, 글자 쪽은 색상으로 덮여 잘 읽힙니다
   - **+ 배너 추가**, 오른쪽 **▲▼✕**
3. **혜택 강조 · 안내 문구** 탭:
   - **혜택 강조**: 메인 중간 "WHY 담아가넷" 자리입니다. 2~4개, 아이콘은 목록에서 고릅니다.
   - **혜택 안내 문구**: 최근 30일 실제 상담 신청이 5건 미만일 때 '실시간 상담 현황' 자리에 대신 나오는 문구입니다.
     - 실제 신청이 5건 이상이면 이름 일부를 가린 실제 신청 내역이 보입니다.
     - **가짜 신청 내역은 만들 수 없게** 되어 있습니다.
4. **임시저장 → 미리보기 → 사이트에 반영하기**를 누릅니다.

`[스크린샷: 메인 화면 관리 - 맨 위 배너]`

## 6. 사업자 정보 입력하기

1. 위쪽 메뉴 **사이트 설정** → **사업자 정보** 탭을 누릅니다.
2. 상호, 대표자, 대표번호, 이메일, 상담 운영시간, 주소, 사업자등록번호, 통신판매업 신고번호, 개인정보 보호책임자를 입력합니다.
3. **저장**을 누르면 바로 반영됩니다. 반영되는 곳: 홈페이지 맨 아래(푸터), 개인정보처리방침, 이용약관.
   - **대표번호**를 넣으면 화면 오른쪽 아래에 전화 버튼이 생깁니다.
   - **빈칸으로 두면 홈페이지에 표시하지 않습니다.**

`[스크린샷: 사이트 설정 - 사업자 정보]`

### 상담 폼 선택지 (같은 화면 **상담 폼 선택지** 탭)
- 고객 상담 폼과 직원 직접 접수 화면의 **관심 상품**, **희망 통신사** 버튼입니다.
- **+ 추가**, **▲▼** 순서, **✕** 삭제 후 **저장**을 누릅니다.
- 이름을 바꾸거나 지워도 **이미 접수된 DB의 값은 그대로** 남습니다.

### 상담 상태값 (**상담 상태값** 탭)
- 직원이 누르는 상태 버튼(신규·부재·상담중·개통완료·거절 등)입니다.
- **+ 상태 추가**, **이름 바꾸기**, **▲▼** 순서를 바꿀 수 있습니다.
- **완료 상태**: 개통완료·거절처럼 끝난 상태를 표시합니다.
- **숨기기**: 이미 쓰인 상태는 삭제할 수 없어 숨기기만 됩니다.
  - 숨긴 상태는 새로 고를 수 없지만, 그 상태인 기존 DB에는 그대로 보입니다.
- "새 접수 기본" 상태는 숨기거나 삭제할 수 없습니다.

### 알림 (**알림** 탭)
- 새 상담이 들어오면 텔레그램으로 알림을 보냅니다. 알림 받을 방의 **Chat ID**를 넣고 **저장**합니다.
- Chat ID 찾는 법:
  1. 알림 받을 방에 봇을 초대합니다.
  2. 그 방에 아무 메시지나 보냅니다.
  3. 인터넷 주소창에 `https://api.telegram.org/bot(봇토큰)/getUpdates`를 엽니다.
  4. `"chat":{"id": -100…}` 숫자를 복사합니다.
  - 봇 토큰은 납품 체크리스트에 적힌 곳에 있습니다.

## 7. 잘못 고쳤을 때 이전 버전으로 되돌리기

요금표와 메인 화면은 **사이트에 반영할 때마다** 그때 내용이 저장됩니다 (최근 30개).

1. **요금표** 또는 **메인 화면**에서 위쪽 **이전 버전**을 누릅니다.
2. 오른쪽 목록에 날짜·시간·반영한 사람이 나옵니다. 맨 위 **지금 사이트**가 현재 고객 화면입니다.
3. 돌아갈 날짜의 **이 버전으로 되돌리기**를 누르고 확인합니다.
4. 고객 화면이 바로 그때 내용으로 바뀝니다. 되돌린 것도 기록에 남으니, 다시 앞 버전으로 돌아갈 수도 있습니다.

**아직 반영 전이라면** 위쪽 **변경 취소**를 누르세요. 마지막 임시저장 내용으로 돌아갑니다.

`[스크린샷: 이전 버전 목록]`

## 8. 직원 추가·비활성화, 할당량 바꾸기

1. 위쪽 메뉴 **직원 관리**를 누릅니다.
2. **직원 추가**: 아이디, 이름, 초기 비밀번호(8자 이상), 역할(직원), 일일 할당량을 넣고 **계정 생성**을 누릅니다. 초기 비밀번호는 직원에게 따로 알려 주세요.
3. **할당량 바꾸기**: 목록의 **일일 할당량** 숫자를 고친 뒤 옆 **저장**을 누릅니다.
   - 할당량은 [분배 실행] 때 그 직원이 오늘(한국시간) 받을 수 있는 최대 건수입니다.
4. **비활성화**: 그만둔 직원은 **비활성화**를 누릅니다. 바로 로그인할 수 없게 됩니다. 기존 DB 기록은 남습니다.
5. **잠김**: 비밀번호를 5번 틀리면 10분간 잠깁니다. **잠금 해제**로 바로 풀 수 있습니다.
6. **비밀번호 초기화**: 직원이 비밀번호를 잊었을 때 새 비밀번호를 정해 줍니다.

`[스크린샷: 직원 관리]`

## 9. DB 업로드·분배하기

### 엑셀로 DB 올리기
1. 위쪽 메뉴 **엑셀 업로드** → **업로드 양식 다운로드**를 누릅니다.
2. 양식에 이름·연락처(필수), 관심상품·희망통신사·메모(선택)를 채웁니다.
   - 관심상품·희망통신사는 양식의 '작성안내' 시트에 있는 값으로 씁니다.
3. 파일을 고르고 **업로드 · 검증**을 누릅니다.
   - 이 단계에서는 아직 저장되지 않습니다.
   - 신규·중복·오류 건수와 내용이 미리 보입니다.
4. 중복도 저장하려면 **중복 행도 저장**을 체크합니다.
5. **확정**을 누르면 저장됩니다. 오류 행은 저장되지 않습니다.
   - 올린 DB는 **미배정** 상태로 들어갑니다.

### 분배하기
1. **DB 목록** → **분배 실행**을 누릅니다.
2. 미배정 DB가 오래된 순서로 직원들에게 돌아가며 배정됩니다. 각자 **오늘 남은 할당량**만큼만 받습니다.
3. 특정 직원에게 직접 주려면 목록에서 체크한 뒤 **담당자 선택** → **선택 N건 일괄 배정**을 누릅니다.

`[스크린샷: DB 목록 - 분배 실행]`

## 10. 엑셀 다운로드

1. **DB 목록**에서 기간·상태·담당자 등 필터를 고르고 검색합니다.
2. **엑셀 다운로드**를 누르면 지금 목록 조건 그대로 내려받습니다.
3. 다운로드 기록은 보안을 위해 자동으로 남습니다 (누가 언제 받았는지).

## 자주 묻는 질문

**Q. 요금을 바꿨는데 홈페이지에 안 보여요.**
A. **사이트에 반영하기**까지 눌렀는지 확인하세요. 위쪽 상태가 🟩이면 반영된 것입니다. 휴대폰이라면 새로고침해 보세요.

**Q. 미리보기 창 맨 위 파란 띠가 계속 보여요.**
A. 파란 띠의 **미리보기 끝내기**를 누르거나 그 창을 닫으면 됩니다. 고객에게는 보이지 않습니다.

**Q. 실수로 통신사를 지웠어요.**
A. 아직 반영 전이면 **변경 취소**를 누르세요. 이미 반영했다면 **이전 버전**에서 지우기 전 버전으로 되돌리세요.

**Q. 팝업 이미지가 안 올라가요.**
A. 2MB 이하인지, jpg·png·webp인지 확인하세요. 휴대폰 사진은 크기가 커서 2MB를 넘는 경우가 많습니다.
