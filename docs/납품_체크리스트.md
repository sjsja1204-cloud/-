# 담아가넷 납품 체크리스트

납품 전에 아래 항목을 **발주처(대표님)와 함께** 하나씩 확인하세요.
목표는 하나입니다. 개발자가 빠져도 **모든 계정·결제·데이터의 주인이 발주처**여야 합니다.

## 1. 계정 소유권과 결제수단

모든 계정은 **발주처 명의 이메일**로 가입합니다. 결제수단도 **발주처 명의 카드**로 등록합니다.
개발자는 "팀원/멤버" 초대로만 들어가고, 납품할 때 권한을 회수합니다.

| 서비스 | 용도 | 가입 이메일(발주처) | 결제수단(발주처 명의) | 개발자 권한 회수 | 확인 |
|---|---|---|---|---|---|
| 도메인 등록업체 (가비아 등) | 홈페이지 주소 | | ☐ 자동연장 켬 | ☐ | ☐ |
| Cloudflare (Pages) | 홈페이지 화면 배포, 도메인 DNS | | 무료 | ☐ Members에서 제거 | ☐ |
| Cloudflare (R2) | 팝업·배너 이미지 저장 | (위와 동일 계정) | ☐ 카드 등록 필요 (10GB까지 무료) | — | ☐ |
| Render | 서버(API) 실행 | | ☐ 운영 시 Starter 요금 | ☐ Team에서 제거 | ☐ |
| Neon | 데이터베이스(고객 DB) | | ☐ 무료 또는 Launch 요금 | ☐ Organization에서 제거 | ☐ |
| GitHub | 소스코드 보관 | | 무료 | ☐ 저장소 소유권 이전 또는 Collaborator 제거 | ☐ |
| Telegram 봇 | 새 상담 알림 | (봇을 만든 텔레그램 계정) | 무료 | ☐ 아래 2-2 참고 | ☐ |

> **주의**: 개발자 개인 계정에 있는 서비스는 개발자 계정이 정지되면 같이 멈춥니다. 반드시 발주처 계정으로 옮기세요.

### 1-1. 납품 직후 꼭 바꿀 것
- ☐ 관리자 비밀번호 변경: 관리자 화면 **내 계정**
- ☐ 개발 중 만든 테스트 직원 계정 **비활성화**: **직원 관리**
- ☐ Render의 `JWT_SECRET` 새 값으로 교체. 모든 로그인이 풀리니 바꾼 뒤 다시 로그인하세요.
- ☐ Neon DB 비밀번호 재발급 (Neon → Roles → Reset password)
  - 재발급 후 Render의 `DATABASE_URL`도 새 값으로 바꿉니다.
- ☐ R2 액세스 키 재발급 후 Render의 `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY` 교체

### 1-2. 텔레그램 봇 넘기기
- 봇을 개발자가 만들었다면: @BotFather → `/mybots` → 봇 선택 → **Transfer Ownership**으로 발주처 텔레그램 계정에 넘깁니다.
- 또는 발주처가 @BotFather에서 새 봇을 만들고, 그 토큰을 Render `TELEGRAM_BOT_TOKEN`에 넣습니다.

## 2. 환경변수 목록

### 2-1. Render (서버) 환경변수
Render → 서비스(damaganet-api) → **Environment**에 있습니다.

| 이름 | 뜻 | 예시 / 비고 |
|---|---|---|
| `DATABASE_URL` | Neon 데이터베이스 접속 주소 | `postgresql://…neon.tech/…?sslmode=require` **외부 유출 금지** |
| `JWT_SECRET` | 로그인 쿠키 서명 키 | 32자 이상 무작위. 바꾸면 전원 로그아웃 **외부 유출 금지** |
| `TELEGRAM_BOT_TOKEN` | 텔레그램 봇 토큰 | `123456:ABC…` **외부 유출 금지**. 비우면 알림이 꺼집니다 |
| `TELEGRAM_CHAT_ID` | 알림 받을 방 (예비값) | 관리자 화면 **사이트 설정 → 알림**에 넣은 값이 우선입니다 |
| `R2_ACCOUNT_ID` | Cloudflare 계정 ID | Cloudflare 대시보드 오른쪽 |
| `R2_ACCESS_KEY_ID` | R2 접근 키 ID | R2 → Manage API Tokens |
| `R2_SECRET_ACCESS_KEY` | R2 접근 비밀키 | **외부 유출 금지** |
| `R2_BUCKET` | 이미지 저장 버킷 이름 | 예: `damaganet-images` |
| `R2_PUBLIC_URL` | 이미지 공개 주소 | `https://pub-xxxx.r2.dev` 또는 `https://img.도메인` |
| `CLIENT_ORIGIN` | 홈페이지 주소 (쉼표로 여러 개) | `https://damaganet.pages.dev,https://www.도메인` |
| `TRUST_PROXY` | 프록시 단계 수 | `2` (Cloudflare → Render). 바꾸지 마세요 |
| `COOKIE_SAMESITE` | 로그인 쿠키 정책 | `lax`. 바꾸지 마세요 |
| `NODE_ENV` | 실행 모드 | `production` |
| `NODE_VERSION` | Node.js 버전 | `22` |
| `PORT` | 서버 포트 | Render가 자동 지정. 넣지 않습니다 |

> **R2 5개 값이 하나라도 비어 있으면** 업로드한 이미지가 서버 디스크에 저장됩니다. Render 무료/Starter 디스크는 재배포 때 지워지므로 **운영에서는 R2를 꼭 설정**하세요. 서버 로그에 경고가 뜹니다.

### 2-2. Cloudflare Pages (화면) 환경변수
Cloudflare → Workers & Pages → 프로젝트 → **Settings → Variables and Secrets**에 있습니다.

| 이름 | 뜻 | 예시 |
|---|---|---|
| `API_ORIGIN` | Render 서버 주소 | `https://damaganet-api.onrender.com` |
| `NODE_VERSION` | 빌드용 Node.js 버전 | `22` |

## 3. DB 백업 확인 방법 (Neon)

Neon은 데이터를 자동으로 보관합니다. 일정 기간 안의 **원하는 시점으로 되돌릴 수 있습니다** (Point-in-time restore).

- 보관 기간은 요금제마다 다릅니다. 무료는 짧고, 유료는 더 깁니다.
- 현재 값은 Neon → 프로젝트 → **Settings → Instant restore / History retention**에서 확인합니다.

### 매달 1번 확인
1. ☐ Neon 대시보드 → 프로젝트 → **Branches**에서 `main` 브랜치가 **Active**인지 봅니다.
2. ☐ **Settings → History retention** 기간을 확인합니다. 운영 중이면 7일 이상을 권장합니다.
3. ☐ **Monitoring**에서 저장 용량을 확인합니다. 무료 한도(0.5GB)에 가까우면 요금제를 올립니다.

### 따로 백업 파일 받기 (분기 1번 권장)
- 가장 쉬운 방법: 관리자 화면 **DB 목록 → 엑셀 다운로드** (기간 필터 없이)로 고객 DB 전체를 엑셀로 보관합니다.
- 전체 백업 (개발자 또는 PC에 PostgreSQL 설치 시):
  ```powershell
  pg_dump "DATABASE_URL 값" -Fc -f damaganet_백업_날짜.dump
  ```
  받은 파일은 **암호를 건 저장소**에 보관합니다. 고객 개인정보가 들어 있습니다.

### 되돌려야 할 때
- Neon → **Restore** → 시점을 고르면 그 시점의 DB로 되돌립니다. 먼저 **Branch로 복원**해서 확인한 뒤 바꾸는 것이 안전합니다.
- 요금표·메인 문구만 잘못된 경우에는 DB 복원이 필요 없습니다. 관리자 화면 **이전 버전**으로 되돌리세요 (매뉴얼 7번).

## 4. 납품 최종 점검

- ☐ 홈페이지에서 상담 신청 → 관리자 **DB 목록**에 들어오고 텔레그램 알림이 오는지 확인
- ☐ 관리자 **요금표**에서 숫자 하나 바꿔 **사이트에 반영하기** → 홈페이지 확인 → **이전 버전**으로 되돌리기
- ☐ **팝업**에 이미지 올리기 → 홈페이지에 뜨는지 확인 → 끄기
  - 이미지 주소가 `R2_PUBLIC_URL`로 시작해야 R2에 저장된 것입니다.
- ☐ **사이트 설정 → 사업자 정보** 실제 값 입력 → 푸터·개인정보처리방침에 반영됐는지 확인
- ☐ 개인정보처리방침·이용약관 내용을 실제 사업 내용과 대조 (법률 검토 권장)
- ☐ `docs/관리자_매뉴얼.md`의 `[스크린샷: …]` 자리에 실제 화면 캡처 넣기
- ☐ 발주처에 전달: 관리자 로그인 주소, 아이디 (비밀번호는 직접 바꾸도록), 이 체크리스트, 관리자 매뉴얼
